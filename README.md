# 📦 Smart Stock Management System

A web-based inventory management system built with Python Flask and SQLite.

## 🚀 Features
- Add, update, delete and view stock items
- User authentication and admin dashboard
- Sales and restock tracking
- Receipt generation
- Clean and intuitive UI

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3
- **Database:** SQLite
- **Tools:** Git, VS Code

## 📂 Project Structure
- `app.py` - Main application file
- `schema.sql` - Database schema
- `templates/` - HTML pages
